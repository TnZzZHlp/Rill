## 目标与范围

从显式 URL 前缀提取 HTTP/HTTPS 目标，支持明确开启的匿名模式。

排除 OTLP/追踪及新增 metrics 能力、差距文档 2.11、生产切换，以及分配给其他阶段的实现。现有观测代码删除属于用户后续独立工作，不在本阶段执行。

## 设计

### 模块边界与目标路径

src/proxy/、src/config/、src/http_policy/、tests/dynamic_proxy.rs 与 tests/dynamic_proxy/。

业务逻辑放在所属模块，main/CLI 仅编排。共享配置、动作和资源类型经统一管线准备；请求固定一个快照，各过滤器不得重新读取活动配置。

### 接口与运行行为

动态代理使用独立的 public-only 地址策略，不继承固定上游允许内网的默认值。目标默认端口 80/443，其他显式开放；拒绝 userinfo、非 HTTP 协议、非公网与自身入口。每轮 DNS 全候选检查，连接固定已批准地址，禁止二次按域名解析；不自动跟随 Location。缺失匿名显式开关时必须有配置的鉴权，隐蔽前缀不算鉴权。

外部输入可恢复、脱敏、严格拒绝未知字段；资源超限按冻结契约失败。新增文件/状态不得在失败候选中污染活动资源。所有测试和验证在隔离环境进行，不操作生产 Caddy。
