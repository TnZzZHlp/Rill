## 设计

### 模块边界与目标路径

拟新增 src/webdav/、src/auth/、src/static_files/（仅复用安全打开能力）、src/runtime/、src/config/、tests/webdav.rs 与 tests/webdav/。

业务逻辑放在所属模块，main/CLI 仅编排。共享配置、动作和资源类型经统一管线准备；请求固定一个快照，各过滤器不得重新读取活动配置。

### 接口与运行行为

WebDAV 独立于只读静态动作；写 root 必须显式配置，并与鉴权绑定。独占锁由进程级存储注册表拥有，身份基于显式存储 ID 和准备后的 root 身份，不由短命快照拥有。Reload 保留相同存储的锁；危险 root 身份变更拒绝或要求重启，不能泄露旧数据。重启锁失效。属性/锁与文件的事务和失败恢复边界按 001 定稿，不承诺跨文件系统原子事务。

外部输入可恢复、脱敏、严格拒绝未知字段；资源超限按冻结契约失败。新增文件/状态不得在失败候选中污染活动资源。所有测试和验证在隔离环境进行，不操作生产 Caddy。
