## 设计

### 模块边界与目标路径

src/http_policy/、src/config/、src/proxy/headers.rs、src/static_files/、tests/http_proxy/、tests/static_files/。

业务逻辑放在所属模块，main/CLI 仅编排。共享配置、动作和资源类型经统一管线准备；请求固定一个快照，各过滤器不得重新读取活动配置。

### 接口与运行行为

头规则支持设置/追加/删除及受控替换，含 Location 替换、Vary 去重合并、响应 Content-Type 条件。变量只暴露经验证的客户地址、上游 authority、路径、受控捕获及固定主机身份，不能拼任意秘密。Host 改写不改变 TLS 验证名。静态候选与错误页继续受同一 root FD 约束。错误链区分本地处理错误和上游正常 404，禁止把鉴权失败、非法路径或已开始响应改成成功页面。

外部输入可恢复、脱敏、严格拒绝未知字段；资源超限按冻结契约失败。新增文件/状态不得在失败候选中污染活动资源。所有测试和验证在隔离环境进行，不操作生产 Caddy。
