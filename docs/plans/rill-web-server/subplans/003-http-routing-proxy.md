## 设计与模块边界

- 拟议目标路径：src/routing/、src/proxy/、src/runtime/state.rs、src/cli/、src/observability/logging.rs。
- routing 独立于转发；请求开始固定快照，匹配后交给动作处理器。Pingora 承担 HTTP 解析、连接池和流式 I/O，不实现第二套网络栈。
- main/CLI 仅编排，不持有业务规则；模块通过明确接口通信，不直接改写其他模块内部状态。
- 外部错误必须可恢复、可定位并脱敏。所有配置更新复用统一验证与准备流程，禁止绕过运行时事务边界。
