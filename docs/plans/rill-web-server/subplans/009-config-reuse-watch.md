## 设计与模块边界

- 拟议目标路径：src/config/、src/runtime/reload.rs、src/observability/logging.rs、examples/、docs/。
- Snippet 在标准化阶段展开，不与 Profile 共用含混语义。文件监听只触发既有 Reload 管线，不能绕过完整校验和单点提交。
- 用户访谈 `fb950ddd` 已批准为现有 `nix 0.31.3` 启用 `inotify` feature，不新增 crate；`watch` 默认为关闭且作为启动项，改变需重启。
- 同一访谈确认独立 Snippet 名称空间、单名引用与嵌套、拒空定义及全定义校验；最大引用深度 64、全配置复制片段路由 4096、展开步骤 16384、逻辑 payload 8 MiB，复制前检查预算。
- main/CLI 仅编排，不持有业务规则；模块通过明确接口通信，不直接改写其他模块内部状态。
- 外部错误必须可恢复、可定位并脱敏。所有配置更新复用统一验证与准备流程，禁止绕过运行时事务边界。
