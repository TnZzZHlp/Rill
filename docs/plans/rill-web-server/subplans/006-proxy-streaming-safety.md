## 设计与模块边界

- 拟议目标路径：src/proxy/、src/config/、src/runtime/、src/observability/logging.rs。
- 上游策略封装 URL、解析/地址访问检查、证书验证、超时和头部规则。HTTP 协议一致性依靠 Pingora，应用层只添加明确策略，不进行危险的报文二次解释。
- main/CLI 仅编排，不持有业务规则；模块通过明确接口通信，不直接改写其他模块内部状态。
- 外部错误必须可恢复、可定位并脱敏。所有配置更新复用统一验证与准备流程，禁止绕过运行时事务边界。

## 风险与缓解

默认 HTTP 超时会误伤长连接，宽松目标检查又可能引入 SSRF；以场景化策略和明确允许目标解决。
