## 设计与模块边界

- 拟议目标路径：src/tls/、src/config/validate.rs、src/runtime/、src/proxy/、src/cli/check.rs。
- tls 构建不可变证书集合，SNI 选择只读快照。证书加载和日志脱敏不放在请求热路径。启动/check/reload 复用相同的证书预检查。
- main/CLI 仅编排，不持有业务规则；模块通过明确接口通信，不直接改写其他模块内部状态。
- 外部错误必须可恢复、可定位并脱敏。所有配置更新复用统一验证与准备流程，禁止绕过运行时事务边界。
