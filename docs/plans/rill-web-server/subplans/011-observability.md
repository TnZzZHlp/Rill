## 设计与模块边界

- 模块边界：config 负责 server-only 观测配置；observability 的 owner、request、access/logging、metrics、metrics_server 分别负责进程资源、请求生命周期、有界日志、固定指标注册表及受限端点；tracing 使用独立 SDK 适配模块。proxy/runtime 只接线并报告受控事件，不在入口堆业务。
- 可观测性模块拥有事件模型和导出器，业务模块仅报告受控字段。指标标签禁止原始 URL、客户端标识等无界值；日志和追踪不得暴露密钥或默认记录敏感头。
- main/CLI 仅编排，不持有业务规则；模块通过明确接口通信，不直接改写其他模块内部状态。
- 外部错误必须可恢复、可定位并脱敏。所有配置更新复用统一验证与准备流程，禁止绕过运行时事务边界。
