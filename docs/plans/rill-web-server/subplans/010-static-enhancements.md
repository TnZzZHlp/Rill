## 目标与范围

在不放宽目录约束的前提下提供预压缩、可控缓存、自定义错误页和可选目录浏览。

包含本阶段任务明确列出的能力。排除其他阶段的实现及原文非目标功能；不得借本阶段扩大范围。

## 前置条件

阶段 008 已通过验收并完成各自独立提交。
实施前阅读目标文件与工作区状态，保留现有用户编辑。验证需要真实配置、证书或上游时，在受控环境准备，不使用真实私钥作为仓库内容；新增依赖或测试工具须遵守批准边界。

## 设计与模块边界

- 实际模块：src/static_files/ 下 representation、validator、cache、error_page、listing；config 负责解析与来源，runtime 负责共享预算/代次绑定，scripts/bench 提供独立测量入口，examples 和 docs 提供部署语义。
- 所有表示和错误页复用安全打开层。缓存必须有容量上限和明确失效策略；配置代次变化、文件变化和压缩表示是缓存键/验证器设计的一部分。
- main/CLI 仅编排，不持有业务规则；模块通过明确接口通信，不直接改写其他模块内部状态。
- 外部错误必须可恢复、可定位并脱敏。所有配置更新复用统一验证与准备流程，禁止绕过运行时事务边界。

## 风险与缓解

增强组合容易返回错误表示或泄露旧 root 文件；采用按表示和配置代次隔离的缓存及统一安全打开层。
