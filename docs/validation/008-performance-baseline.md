## 环境与口径

- 同机隔离 loopback 网络，无外网或公共监听；目标 CPU 0,1，客户端 2,3，后端 4,5。两目标顺序运行，不承诺宿主独占。每进程 AS 2 GiB、CPU 6000 秒、nproc 128、nofile 4096、文件 512 MiB；临时磁盘 8 GiB、总墙钟 7200 秒。AS 是每进程限制，不是相同的整进程树内存上限。
- 对照为缓存 `nginx:1.28-alpine` 中的 Nginx 1.28.3，二进制 SHA-256 `bf30939947d1d9ac8dccb6477c336e612760d3ee3c43991085fd54b4c7d741d8`；两 worker、sendfile 开启、open_file_cache 关闭、上游 keepalive 32、代理缓冲关闭。Rill 和 Nginx 的 TLS 库版本不同，不能假设是相同实现。
- HTTP/1.1 固定并发 8，每场景三轮、预热 2 秒、正式测量 30 秒；HTTP/HTTPS × 1 KiB 代理、1 KiB 静态、16 MiB 静态 × cold/warm，共 72 轮。HTTPS 指入站 TLS，上游基准后端为 HTTP；不是 HTTP/2 或 HTTPS 上游性能测试。
- WS/SSE 使用明文 HTTP，10/100 连接各三轮、每轮 60 秒，共 24 轮。另有空闲六轮、每轮 60 秒，以及 Reload 六轮、每轮 60 秒加 2 秒预热，既有 HTTP 8、WS 10、SSE 10 并存，每 10 秒切换一次、共五次。
- TLS 验证 CA、名称和 SNI，禁止 session reuse。cold 指新 TCP/TLS 连接，不是冷磁盘；未清 OS 页缓存。
- 每请求验证状态、长度与内容。仅幂等 GET 在旧 warm 连接的空头 EOF 或头部阶段 reset 时允许一次新连接重试；部分头 EOF 和任何 body 失败不重试。逻辑请求错误与物理 attempts、idle-close、header-reset retry 分开统计，时延包含重连。
- 分位数采用成功 issue cohort 的最近秩，包含截止后完成的在途请求；名义吞吐仅统计窗口内完成量，另报含 drain 的 cohort 速率。原始 CSV 可复算，不能混用两种分母。
- 资源采样覆盖预热和测量，每秒采样服务进程树、客户端及后端。CPU 100% 为一逻辑核；RSS 求和可能重复计入共享页，HWM 求和不是同时峰值，未测 PSS，短生进程可能漏采。空闲是在负载之后测量，不是刚启动的最小常驻占用。
- 这是闭环 C8 负载，存在协调遗漏、客户端和后端限制。client warning 为客户端单核 CPU ≥90% 或事件循环最大滞后 ≥100 ms 的启发式提示；没有警告也不能证明饱和。不能把这里的吞吐解释成服务器容量上限。

脚本与参数说明见 [scripts/bench/README.md](../../scripts/bench/README.md)。
