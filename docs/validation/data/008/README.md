# 008 实测数据

`before/`、`after/` 分别保存修复前后各轮摘要、资源 CSV、环境及完整原始产物清单。两份 `*-selection.json` 记录纳入 Git 的文件校验值和独立原始目录；`*-aggregate.json` 是三轮单轮指标的中位数汇总。

资源 CSV 保留原始 CRLF 字节；限定于本目录的 Git 属性禁止自动换行转换，校验值按原始字节计算。

逐请求、逐事件 CSV/GZ 独立保留，不纳入 Git；完整清单中的这些文件不应在本目录查找。两套完整标准结果及原始数据均已独立复核；具体范围与解释见性能报告。

验收与适用边界见 [008 验证记录](../../008-p0-validation-deployment.md)。
